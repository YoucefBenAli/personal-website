# Youcef — Personal Website

A terminal-inspired personal website for Youcef, a backend software engineer based in Ottawa, Canada.

Explore my background, technical toolkit, experience, and AI coding setup through a small interactive terminal. Type a command or click one to get started.

## Explore

| Command | What you'll find |
| --- | --- |
| `whoami` | A little about me |
| `stack` | Languages, tools, and infrastructure I work with |
| `experience` | My professional background |
| `ai` | My AI coding setup |
| `github` | My GitHub profile |
| `contact` | How to get in touch |
| `help` | All commands and keyboard shortcuts |

Use **Tab** to complete commands and **↑ / ↓** to browse command history. Try `theme` to cycle through cyan, lime, and amber palettes, or `clear` to start with a clean terminal.

## Built with

Plain HTML, CSS, and JavaScript—no framework, build step, external fonts, or runtime dependencies. The site includes responsive styling, clickable commands, and a theme preference saved locally in your browser.

## Project structure

- `index.html` — website entry point
- `config.js` — personal content and links
- `assets/terminal.css` — styles and themes
- `assets/terminal.js` — terminal interactions
- `tests/terminal.cjs` — Playwright smoke tests
